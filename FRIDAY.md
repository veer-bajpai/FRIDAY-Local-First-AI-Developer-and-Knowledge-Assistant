# Friday Project Rules

- Stack: Python 3.11+ / FastAPI / Ollama, Node.js 20+, and Next.js.
- Use type hints for Python changes; keep the existing ESLint and Ruff conventions.
- Run `pytest` and `npm run lint` after changing code when the relevant tools are available.
- Never edit `.env`, secrets, generated output, or files under `vendor/`.
- Keep all file operations inside the current workspace and preserve permission prompts.
- Network operations require approval unless the project settings explicitly allow them.
